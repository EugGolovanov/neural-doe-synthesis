# Выводы главы 3.

1. С использованием синхронизации ПВМС и камеры создана экспериментальная установка для измерений фазового сдвига ПВМС.
2. Получена зависимость фазового сдвига от уровня сигнала и времени от начала кадра. Значение максимальной глубины фазовой модуляции составило 3,58π, погрешность измерений - 0,05π. На основании полученной зависимости создана калибровочная кривая для ЖК ПВМС, которая обеспечила линейность модулятора при его работе в режиме синхронизации с камерой или лазером.
