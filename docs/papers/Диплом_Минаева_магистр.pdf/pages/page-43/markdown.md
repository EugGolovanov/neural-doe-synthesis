### 4.2 Результаты для объектов, расположенных по центру рабочей области

На рис. 4.3 представлены примеры трехмерных объектов, оптически восстановленных с ДОЭ, синтезированных многоплоскостными методами, отобранными в результате анализа в Главе 1.
