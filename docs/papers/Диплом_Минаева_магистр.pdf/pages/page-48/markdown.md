Как видно из рис. 4.5(е-к), для ДОЭ, синтезированного методом последовательный «пинг-понг», качество восстановленного изображения уступает остальным изображениям: восстанавливается только последняя плоскость объемного изображения. Данные результаты совпадают с результатами численного моделирования, при котором изображения, восстановленные с ДОЭ, синтезированных методом последовательный «пинг-понг» также визуально неразличимы (см. рис. 2.3(б)).

При восстановлении изображений с ДОЭ, синтезированных методами суперпозиций (рис. 4.5(а-д), глобальный «пинг-понг» (рис. 4.5(л-п) и на основе невыпуклой оптимизации (рис. 4.5(р-ф), качество изображений схожее: объекты в разных плоскостях хорошо видны. При отдельном рассмотрении сфокусированного объекта рассматриваются его отдельные пиксели.
