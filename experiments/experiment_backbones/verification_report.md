# Выполненные проверки

Окружение: Python 3.12.12, torch 2.10.0, NumPy 2.2.6, Pillow 10.4.0; CPU, один поток.

`python -m experiments.experiment_backbones.verify`:

- Центральная разность по нормированному случайному направлению входа, шаг 1e-5, float64: абсолютная ошибка FNO-слоя 1.70e-12, selective SSM 1.28e-12; допуск 1e-7 учитывает округление и ошибку разности второго порядка. Это локальная проверка производных, не доказательство правильности всей архитектуры.
- На полной сетке 128×128, K=2, уменьшенных ширинах: относительная невязка градиентов с checkpoint и без него равна 0 для U-Net/FNO/SSM, допуск 1e-5 для float32.
- Нулевая выходная голова даёт строго нулевую коррекцию; затем голова получает ненулевые тестовые веса для проверки распространения градиента в ранние слои.
- Градиенты и параметры после одного Muon-обновления конечны; норма изменения головы около 0.00696436 для всех трёх моделей. Это не проверка долгосрочной устойчивости обучения.

`python -m experiments.experiment_unrolled_cnn.verify` после изменения общего runner:

- checkpoint max error = 0;
- относительные ошибки производной полной развёртки: 5.47e-8, 1.84e-8, 8.26e-8 (допуск 1e-4);
- ошибка мощности 2.22e-16 (допуск 1e-12);
- относительная производная общей фазы 5.69e-18 (допуск 1e-12);
- старый CNN/GS + Muon smoke-test прошёл.

Дополнительно выполнен сквозной `run_experiment` для всех четырёх моделей с **основными ширинами**: seed=17, train/validation/test=1/1/1, одна эпоха, K=2, одна итерация GS + Muon. Получены пять строк summary и PNG-артефакты, best/last checkpoints и истории. Число параметров: CNN 1728, U-Net 6336, FNO 2000, axial Mamba-like 1248. Артефакты этого технического запуска сохранены во временном системном каталоге, не являются результатами репозитория или сравнением качества.

## Замена CNN/U-Net на ConvNeXt-Tiny

`python -m experiments.experiment_backbones.verify_convnext` выполнен для обоих полных backbone (не уменьшенных копий), CPU float32, seed=123, K=2:

- Число параметров `cnn_convnext_tiny`: 27 837 384; `unet_convnext_tiny`: 27 846 216.
- Формы backbone: `[1,96,32,32]`, `[1,192,16,16]`, `[1,384,8,8]`, `[1,768,4,4]`; выход фазы `[1,1,128,128]`.
- Максимальная ошибка нулевой головы: 0 для обоих вариантов.
- После ненулевой инициализации головы относительная невязка всех градиентов с checkpoint и без него: 0 для обоих; допуск 1e-5.
- Все градиенты и параметры после одного Muon-обновления конечны, включая affine-параметры и LayerScale; изменение головы 0.006964366 / 0.006964365.
- Центральная разность по входу отдельного ConvNeXt-блока в float64: абсолютная ошибка 8.63e-13 при шаге 1e-5 и допуске 1e-7.

Это проверки вычислительного графа, а не качества или устойчивости обучения ConvNeXt. Полное обучение, подбор lr, PNG-оценка обученных новых вариантов и измерение памяти не выполнены. Сквозной smoke-test выше относится только к прежним компактным CNN/U-Net.

Полный запуск 24/6/6 × 10 эпох × 3 seed не выполнен. Пиковая память, оптимальные гиперпараметры, преимущество моделей, непрерывная физическая сходимость и перенос на реальные данные не проверялись.
