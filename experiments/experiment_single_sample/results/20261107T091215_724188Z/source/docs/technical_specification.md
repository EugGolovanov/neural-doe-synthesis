# Техническое задание: синтез четырёхплоскостного фазового ДОЭ

## 1. Исходные параметры

- Четыре объектных изображения, каждое 128×128 пикселов.
- Один общий фазовый ДОЭ размером 128×128 пикселов для всех четырёх изображений.
- Фаза каждого пиксела ДОЭ: от −π до +π.
- Метод восстановления: прямой численный расчёт дифракции Френеля по выражению с одним преобразованием Фурье на каждую плоскость.
- Расстояния от ДОЭ, в порядке соответствующих входных изображений: 24,1; 25,3; 26,5; 27,7 мм.
- Длина волны лазера: 532 нм.
- Линейный размер пиксела ПВМС: 10 мкм.

## 2. Вход нейронной сети

Четыре изображения PNG размером 128×128 пикселов, 8 бит на пиксел, одноканальные (не RGB).

## 3. Результаты работы

1. Изображение синтезированного ДОЭ: PNG, 128×128, 8 бит, один канал. Код 0 соответствует фазе −π, код 255 — фазе +π.
2. Четыре восстановленных изображения: PNG, 128×128, 8 бит, один канал. Восстановление выполняется численным расчётом дифракции Френеля из синтезированного ДОЭ.
3. Для каждой из четырёх пар «исходное — восстановленное» привести коэффициент корреляции Пирсона и индекс структурного сходства SSIM: всего восемь значений.

## 4. Финальные материалы для экспертов

Передать все созданные материалы: программные коды, наборы данных и остальные материалы проекта, включая исходные и выходные изображения и результаты оценки.

## 5. Не определено исходным ТЗ

ТЗ не задаёт профиль и мощность освещения, среду распространения, апертуру и коэффициент заполнения ПВМС, физический размер выходных изображений, гамма-коррекцию, нормировку интенсивностей при сохранении PNG, параметры SSIM, архитектуру и обучение сети, пороги качества метрик.

Принятые расчётные соглашения и ограничения приведены отдельно в `doe_physics.md`; они не являются дополнительными требованиями заказчика. Для физического эксперимента необходимы согласование этих параметров и калибровка фазового отклика ПВМС.
