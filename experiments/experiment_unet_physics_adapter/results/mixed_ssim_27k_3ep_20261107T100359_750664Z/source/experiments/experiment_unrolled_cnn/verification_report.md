# Отчёт численной проверки реализации

Команда из корня: `python3 -m experiments.experiment_unrolled_cnn.verify`.

Окружение фактического запуска: Python 3.12.12, macOS-26.2-arm64-arm-64bit, PyTorch 2.10.0, NumPy 2.2.6, Pillow 10.4.0; CPU, один поток. Основные численные проверки — float64/complex128, seed=123, K=2, width=2; сквозной smoke — float32/complex64, seed=17, одна эпоха, train/validation/test=3/1/1, baseline=1 шаг. Это не стандартная конфигурация полного эксперимента.

| Свойство и мера ошибки | Получено | Допуск |
|---|---:|---:|
| Checkpoint/non-checkpoint: max abs разности градиентов весов | 0 | 10⁻¹¹ |
| Полная производная развёртки: относительная ошибка центральной разности, h=10⁻³ | 5,4674×10⁻⁸ | 10⁻⁴ хотя бы для одного h |
| То же, h=10⁻⁴ | 1,8446×10⁻⁸ | 10⁻⁴ |
| То же, h=10⁻⁵ | 8,2586×10⁻⁸ | 10⁻⁴ |
| Batch=1 против двух одинаковых примеров: max abs разности фаз | 0 рад | 10⁻¹¹ рад |
| Дискретная мощность: максимальная относительная ошибка по плоскостям | 2,2204×10⁻¹⁶ | 10⁻¹² |
| Производная общей фазы: abs(sum(g))/sum(abs(g)) | 5,6863×10⁻¹⁸ | 10⁻¹² |

Все веса после Muon конечны. Обоснование допусков: ошибки округления float64 для алгебраических инвариантов и сравнения checkpoint; для центральной разности — баланс усечения O(h²), округления и кусочной гладкости max. Проверяется направление в весах первой свёртки коррекции при ненулевой выходной голове, поэтому производная проходит через оба физических шага, а не только через последнюю голову.

Сквозной запуск прошёл: генерация и чтение PNG, одна эпоха с Muon, validation-выбор и повторная загрузка checkpoint, CNN и GS + Muon на test, экспорт и повторное чтение масок, по четыре пары метрик у каждого метода. Validation loss: 0,0272392 до обучения, 0,0272363 после smoke-эпохи; это только диагностические значения, не свидетельство преимущества CNN. Артефакты smoke создавались во временном каталоге и были удалены; скрипт позволяет повторить проверку.

Регрессия: `python3 experiments/experiment_gs_muon/verify_muon.py` прошла после добавления пакетных импортов. Невязка неподвижной точки GS 6,474×10⁻¹⁶; относительные ошибки направленной производной Muon для h=10⁻³/10⁻⁴/10⁻⁵: 4,685×10⁻⁶ / 4,685×10⁻⁸ / 4,677×10⁻¹⁰; ошибка нулевого градиента 0; ошибка тождественного SSIM 0; Pearson постоянной цели — None.

Не выполнены: полное обучение по CONFIG, оценка преимущества CNN на трёх seed, подбор гиперпараметров, измерение пиковой памяти, физическая проверка сходимости по подразделению пикселей и независимому оператору. Проверка сопряжённости и аналитического градиента здесь не добавлялась. Результаты не доказывают точность непрерывной физической модели.
