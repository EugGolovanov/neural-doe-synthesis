## Заключение.

Целью данной выпускной квалификационной работы являлся анализ, и реализация методов синтеза фазовых дифракционных оптических элементов (ДОЭ) для задачи формирования трехмерных сцен с использованием жидкокристаллического пространственно-временного модулятора света (ЖК ПВМС).

В ходе работы были решены следующие задачи:

1. Проведен анализ существующих групп методов синтеза фазовых ДОЭ объемных сцен. Для дальнейшей работы были отобраны поточечные и многоплоскостные методы.

2. Синтезированы фазовые ДОЭ объемных объектов отобранными методами и проведены численные эксперименты по их восстановлению. Наиболее эффективными оказались многоплоскостные методы. Для данных методов коэффициент корреляции по Пирсону между исходным и восстановленным объемными объектами достигал 0,94.

3. Исследованы фазовые характеристики ЖК ПВМС. Получена экспериментальная зависимость фазового сдвига от уровня сигнала и времени начала показа кадра. Значение максимальной глубины фазовой модуляции составило 3,58π, погрешность измерений - 0,05π. На основании полученной зависимости была создана калибровочная кривая для ЖК ПВМС, которая обеспечила линейность модулятора при его работе в режиме синхронизации с камерой или лазером.

4. Проведены оптические эксперименты по восстановлению объемных объектов с фазовых ДОЭ, синтезированных отобранными методами. Данные эксперименты подтвердили результаты численного моделирования, продемонстрировав эффективность многоплоскостных методов.
