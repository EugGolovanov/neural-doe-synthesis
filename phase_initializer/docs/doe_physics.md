# Физика и протокол итогового варианта

Этот документ фиксирует соглашения рабочего кода `phase_initializer`, без зависимости от архивных экспериментов и корневой папки `docs`. Алгоритм запуска описан в [network_phase.md](network_phase.md).

## Вход и геометрия

Четыре отдельных одноканальных uint8 PNG размером 128×128 задают целевые интенсивности `T=B/255`, без гамма-преобразования, resize или crop. Порядок осей — plane/y/x. Порядок расстояний: 24.1, 25.3, 26.5, 27.7 мм. Выход — одна общая фаза `[128,128]` в радианах.

Фиксированные параметры: N=128, шаг ДОЭ Δ=10⁻⁵ м, λ=532×10⁻⁹ м. Освещение — плоская волна единичной амплитуды на квадратной апертуре NΔ=1.28 мм, вне апертуры поле нулевое. Модель скалярная, параксиальная, без потерь и аберраций. Пиксел представлен одним комплексным отсчётом. Padding физической апертуры и интегрирование по детектору не выполняются.

## Одно-FFT Френель

Координаты центров входных отсчётов:

`x_m=(m−N/2)Δ`, `y_n=(n−N/2)Δ`, индексы от 0 до N−1.

Для каждой плоскости:

```text
U0 = exp(i phi)
chirp_j = exp(i π (x²+y²)/(λ z_j))
S_j = fftshift(fft2(ifftshift(U0 * chirp_j), norm="backward"))
s_j = Δ²/(λ z_j)
I_j = |s_j S_j|²
```

Сдвиги выполняются только по двум пространственным осям. Входная квадратичная фаза обязательна. Общая фаза распространения, множитель 1/i и выходная квадратичная фаза имеют единичный модуль и опущены, поскольку код рассчитывает интенсивность.

Выходной шаг `Δ_j=λz_j/(NΔ)`, координаты `X_p=(p−N/2)Δ_j`, `Y_q=(q−N/2)Δ_j`. Шаги четырёх сеток: 10.0165625, 10.5153125, 11.0140625, 11.5128125 мкм. Цели трактуются на этих разных native-сетках.

Для выбранной ненормированной FFT:

`Q_j=sum(I_j)=N⁴s_j²`,

`sum(I_j)Δ_j²=N²Δ²`.

Это дискретное равенство мощности, не доказательство точности непрерывной физики. Плоскости — сечения одного поля; их мощности не складываются как независимые расходы энергии.

## Loss и градиенты

Фиксированный масштаб цели `c_j=Q_j/sum(T_j)` зависит только от цели и физики. Полностью чёрные цели исключены из данного алгоритма. Пусть `J_j=I_j/c_j`, `R_j=I_j/(max(I_j)+10⁻¹²)`.

```text
L_amp,j = mean((sqrt(J_j+1e-8) − sqrt(T_j+1e-8))²)
L_j = L_amp,j + 0.5 * (1 − SSIM(R_j,T_j))
L = mean_j(L_j)
```

Epsilon под корнем обеспечивает конечную производную около нулевой интенсивности. Градиент через максимум не останавливается. Фаза при прямой оптимизации не ограничивается clamp или tanh: поле периодично по фазе. Приведение диапазона выполняется только при экспорте PNG.

Внутренний двухшаговый GS+Muon адаптер сети сохраняет исходный обучающий loss: среднее `((I/(max(I)+1e-12))−T)²`. Внешний amplitude+SSIM его не подменяет. Выход сети отсоединяется от графа перед прямой оптимизацией фазы.

## Экспорт и повторное чтение

Точная фаза сохраняется в `phase.npy` без оборачивания и квантования. После повторного чтения из неё рассчитывается `intensity_from_phase.npy`.

Для `doe.png` фаза приводится к `[−π,π)`:

```text
wrapped = (phi + π) mod (2π) − π
D = clip(floor(255 * (wrapped + π)/(2π) + 0.5), 0, 255)
phi_D = −π + 2π D/255
```

D — одноканальный uint8 PNG. Делитель равен 255, а не 256; коды 0 и 255 оптически эквивалентны. Максимальная круговая ошибка округления — π/255 рад.

Итоговые интенсивности рассчитываются из повторно прочитанного `doe.png` и сохраняются в `intensity.npy`. Для каждой плоскости восстановленный PNG:

`C_j=floor(255 I_j/max(I_j)+0.5)`.

Нормировка независима для каждой плоскости, без вычитания фона. Она отображает форму распределения, но скрывает абсолютные различия яркости. Сырые интенсивности, максимумы и шаги сеток сохраняются отдельно.

## Метрики

Обязательные Pearson и SSIM сравнивают исходную цель `T_j` с повторно прочитанным `C_j/255`, без совмещения, crop или resize.

Pearson — скалярное произведение центрированных изображений, делённое на произведение их евклидовых норм. При постоянном изображении значение неопределено: сохраняются `null` и статус `constant_image`.

SSIM использует нормированное гауссово окно 11×11, sigma=1.5, population moments, data_range=1, C1=.01² и C2=.03²:

`SSIM=((2μaμb+C1)(2cov(a,b)+C2))/((μa²+μb²+C1)(var(a)+var(b)+C2))`.

Результат усредняется по центрам с полным окном, без padding. Четыре значения каждой метрики сохраняются отдельно; среднее их не заменяет. `phase_evaluation.json` дополнительно отделяет эффект квантования фазы от округления восстановленных изображений.

## Проверка модели

Локальные численные проверки охватывают дискретную мощность, производную loss, согласованность SSIM и сквозной экспорт. Эти численные проверки не заменяют конечнопиксельную квадратуру, независимое распространение и калибровку реального устройства. Данный рабочий запуск их не выполняет.
