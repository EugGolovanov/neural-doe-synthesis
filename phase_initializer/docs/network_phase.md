# Предобученная сеть → прямая фаза amplitude+SSIM

Запуск из корня: `python3 synthesize_phase.py`.
Окружение: Python 3, PyTorch, NumPy, Pillow (`python3 -m pip install torch numpy pillow`).
Код не импортирует `experiments` и работает без этой папки.

## Входы

`inputs/network_phase/checkpoint_003.pt` — исходный checkpoint из
`mixed_ssim_27k_3ep_20261107T100359_750664Z` (27к, три эпохи).
Он скопирован локально, но *.pt исключены из Git: при передаче проекта нужно
отдельно передать этот файл. Загружать только доверенный checkpoint: используется
`torch.load(weights_only=False)` для исходного формата с metadata.
Четыре `inputs/network_phase/target_{1,2,3,4}.png` скопированы из
`four_planes_recalculation_20261108T012523_553245Z/data` без преобразований.
Это train-пример 0 исходного mixed-data запуска, не независимый test.
Контрольные суммы исходного комплекта: `inputs/network_phase/manifest.json`.

Контракт: четыре непустых одноканальных uint8 PNG 128×128; оси plane/y/x,
интенсивности uint8/255, порядок z=24.1/25.3/26.5/27.7 мм.
Фаза [128,128] в радианах, CPU float64; освещение единичное, λ=532 нм,
шаг ДОЭ 10 мкм, native выходные сетки λz/(128Δ).
Для своих целей можно передать четыре пути в `run(targets=(...))`, без resize.

## Метод

1. Исходная U-Net с прежними весами и **двумя** GS+Muon шагами в каждом
   латентном канале адаптера выдаёт начальную фазу. Внутренний loss остаётся
   исходным maximum-normalized intensity MSE; он не заменяется amplitude+SSIM.
2. Сеть больше не вызывается и не обучается. Нужный внутреннему Muon autograd
   включается только для расчёта сети; её выход отсоединяется от графа.
3. Выполняются 3000 прямых Muon-обновлений 16384 фазовых значений, без GS внутри
   внешнего цикла, без clamp, фазового prior и переобучения сети.

Q_j=128⁴(Δ²/(λz_j))², c_j=Q_j/sum(T_j), J_j=I_j/c_j.
Loss — среднее по четырём плоскостям:

`mean((sqrt(J+1e-8)-sqrt(T+1e-8))²) + 0.5*(1-SSIM(I/(max(I)+1e-12),T))`.

Через максимум проходит градиент. SSIM: Gaussian 11×11, sigma=1.5,
valid окна, population moments, data_range=1, K1=.01, K2=.03.
Muon: lr=.1, momentum=.95, Nesterov, пять Newton–Schulz шагов,
коэффициенты [3.4445,-4.775,2.0315], epsilon=1e-12, scale=1, weight decay=0.
Momentum начинается с нуля. Параметры внешнего цикла явно заданы в `CONFIG`;
внутренние параметры берутся из checkpoint. Веса не замораживаются через
requires_grad_(False), поскольку исходная реализация адаптера строит граф
через латентную фазу; backward по весам и обновления весов не выполняются.

## Файлы

Каждый запуск создаёт новый `results/network_phase_<UTC>/` без перезаписи:
- `initial/`, `final/`: точная phase.npy, doe.png, четыре restored PNG,
  сырые интенсивности и отдельная оценка влияния квантования;
- `summary.json`: восемь метрик до/после, итоговый непрерывный loss и время;
- `history.jsonl`: loss до каждого обновления, в среднем и по плоскостям;
- `phase_*.npy`, `momentum.npy`: промежуточные фазы каждые 100 шагов и конечный momentum;
- `parameters.json`, `environment.json`, `inputs/`, `source/`: фактические
  параметры, seed, версии, checkpoint, цели, хеши, исходники и git diff.

Итог оценивается только на последнем шаге, без скрытого отбора лучшего.
PNG-фаза кодируется с делителем 255, а не 256; восстановления и итоговые
Pearson/SSIM вычисляются после повторного чтения DOE и восстановленных PNG.
Неопределённый Pearson сохраняется как null с причиной.

## Проверки и ограничения

`python3 verify_network_phase.py` проверяет мощность, направленную производную
loss, согласованность двух SSIM-реализаций, квантование и однопроходный smoke.
Выполненные проверки выделенного кода: ошибка мощности 1.47e-16,
относительная ошибка направленной производной 3.44e-8, расхождение SSIM
4.72e-16; точное повторное чтение NPY и PNG-экспорт пройдены.
Двухшаговый внешний smoke выполнен; начальная фаза побитово совпала
с сохранённым исходным двухшаговым network-only результатом (max error=0).
Полный новый запуск на 3000 обновлений не выполнялся.

Короткий запуск всей цепочки:

```python
from synthesize_phase import CONFIG, run
run(config={**CONFIG, 'steps': 2, 'save_every': 2})
```

Это локальная подгонка одной сцены, не проверка обобщения сети. Этот вариант
соответствует ранее исследованной ветке network_C, не GS-start. Новый код
не устраняет обнаруженный разрыв одно-FFT и конечнопиксельной моделей.
Finite-pixel/ASM validation здесь не выполняется; качество реального ДОЭ
не сертифицируется. Полные результаты нового запуска нельзя приписывать
ему до фактического выполнения. Фиксированный seed не гарантирует
побитового совпадения на других платформах.

`experiments/` добавлена в .gitignore, но уже отслеживаемые Git файлы этим
не удаляются из индекса; массовое изменение существующего индекса не выполнялось.
