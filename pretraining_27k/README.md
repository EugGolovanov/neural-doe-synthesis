# Предобучение используемой U-Net на 27 000 четвёрках

Здесь находится только предобучение двухшаговой U-Net, используемой для инициализации фазы в `synthesize_phase.py`. Других экспериментов и диагностических программ в этом модуле нет.

## Файлы

| Файл | Назначение |
|---|---|
| `train.py` | Подготовка данных, три эпохи обучения и итоговая оценка |
| `config.json` | Фактические параметры исходного запуска на 27 000 четвёрках |
| `models.py` | Обучаемая U-Net с двухшаговым GS+Muon адаптером и checkpointing |
| `data.py` | Подготовка фиксированных четвёрок CIFAR-10, Fashion-MNIST и MNIST |
| `physics.py` | Исходный внешний loss MSE+SSIM |
| `algorithms.py` | Muon-обновление весов сети |

Одно-FFT физика, внутренний GS+Muon и экспорт переиспользуются из рабочего пакета `phase_initializer`. Код не импортирует архивные `experiments/` и не обращается к корневой папке `docs/`.

Итоговые веса после трёх эпох: [`../inputs/network_phase/checkpoint_003.pt`](../inputs/network_phase/checkpoint_003.pt). Это исходный checkpoint запуска `mixed_ssim_27k_3ep_20261107T100359_750664Z`, а не результат нового обучения. Он содержит веса, momentum, параметры, номер эпохи и состояния генераторов. Для обычного синтеза повторное обучение не требуется.

## Метод и данные

27 000 обучающих четвёрок — 108 000 изображений, по 36 000 из MNIST, Fashion-MNIST и CIFAR-10. Validation и test содержат по 99 четвёрок. Источники скачиваются через torchvision; подготовка — Pillow L grayscale, BILINEAR до 128×128 и uint8 PNG. Цели читаются как интенсивности uint8/255. Разбиение по исходным изображениям выполняется до формирования четвёрок; совпадающие подготовленные изображения между разбиениями исключаются.

Три эпохи, seed=17, seed данных и перестановок=2026, MPS float32. Batch и microbatch — 256 четвёрок. U-Net: width=8, rank=2, alpha=2, два внутренних GS+Muon шага.

Внешний Muon обучает веса сети с lr=.001. Loss обучения: maximum-normalized intensity MSE + 0.5×(1−SSIM). Внутренний loss адаптера — исходный MSE, lr фазового Muon=.1. Используются полные производные через развёртку и checkpointing активаций, без усечения градиентов.

Это отличается от последующей прямой оптимизации фазы в `synthesize_phase.py`, где применяется amplitude+SSIM и веса сети не обновляются.

## Запуск

Из корня репозитория, Python 3.12 и Apple MPS:

```bash
python3 -m pip install torch==2.10.0 torchvision==0.25.0 numpy Pillow
python3 -m pretraining_27k.train
```

Автоматической смены устройства или batch size нет. Для исходного microbatch=256 требуется достаточно памяти. Это многочасовое обучение; для инференса используйте готовый checkpoint.

Каждый запуск создаёт новую папку `pretraining_27k/results/mixed_ssim_27k_3ep_<UTC>/` с параметрами, входами и их хешами, точным разбиением, порядком примеров по эпохам, историей loss, checkpoint, метриками, версиями и снимком использованного кода. Checkpoint сохраняется после первой и последней эпохи; итоговые Pearson/SSIM считаются после чтения экспортированных масок и восстановлений.

## Связь с исходным кодом

Этот модуль выделен из сохранённого кода исходного запуска: изменены импорты, размещение файлов и сохранение исходников, а не архитектура, подготовка данных, формулы loss или правила обновлений. Экспорт использует текущий рабочий evaluator с дополнительным сохранением точной NPY-фазы; обязательный PNG-протокол сохранён.

На одном примере в CPU float64 проверено точное совпадение с исходной реализацией: фаза, loss, градиенты весов и веса после одного Muon-обновления имеют максимальную абсолютную разницу 0; checkpointing включён. Параметры `config.json` совпадают с параметрами итогового checkpoint.

Полное обучение после выделения не повторялось. Фиксированный seed не гарантирует побитового совпадения на других платформах или версиях библиотек. Для синтеза используется прежний, неизменённый checkpoint.
