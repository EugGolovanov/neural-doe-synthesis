# Численная проверка

Команда из корня: `python -m experiments.experiment_unet_physics_adapter.verify`.
Фактический запуск: CPU, Python 3.12.12, torch 2.10.0, float64, один поток, seed=17, deterministic algorithms включены; параметры из `experiment.py`. Побитовая повторяемость на иных платформах не обещается.

| Свойство / ошибка | Результат | Допуск |
|---|---:|---:|
| Максимальная разность развёртки и исторического GS + Muon, K=2 | 0 | 1e-12 |
| Направленная производная: абсолютная ошибка центральной разности h=1e-4 | 6.7541e-11 | 1e-7 |
| То же, h=1e-5 | 9.2172e-13 | 1e-7 |
| То же, h=1e-6 | 1.5300e-12 | 1e-7 |
| Максимальная разность с основной веткой при B=0 | 0 | 1e-12 |
| Максимальная разность batch=2 и отдельного примера | 0 | 1e-10 |

Допуски сравнения одинаковых операций близки к округлению float64; для конечных разностей выбран более мягкий абсолютный допуск 1e-7 с проверкой трёх шагов из-за вычитания и нелинейных итераций. Проверяется производная проекции результата на случайную карту по случайному нормированному направлению начальной фазы. Это локальная проверка, не гарантия гладкости для всех входов.

Два smoke-обновления всей сети внешним Muon выполнены. Все градиенты конечны; после второго backward нормы градиентов A=3.6818e-7, B=0.185713, W=0.0008705. Loss до обновлений: 0.1550140865 и 0.1548402992; эти числа не являются оценкой качества или доказательством преимущества. Проверен forward под no_grad.

Не выполнены: полное обучение, оценка на held-out данных, экспорт/квантование этой модели, GPU/float32, измерение памяти и скорости, проверка непрерывной физической модели. Физический оператор переиспользован без изменений; здесь отдельно не перепроверялись мощность и сопряжённость.
